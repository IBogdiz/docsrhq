# Counter-Strike 1.6 server

Your Counter-Strike 1.6 server runs on our game panel (Pterodactyl). It is small and starts in seconds.

{% stepper %}
{% step %}
### Start the server

Open your server in the game panel and press **Start**.
{% endstep %}

{% step %}
### Configure it

In the **Files** tab edit `cstrike/server.cfg`: `hostname`, `sv_password`, `rcon_password` and `sv_lan 0`.
{% endstep %}

{% step %}
### Set the maps

Edit `cstrike/mapcycle.txt` to choose the map rotation and set the start map in **Startup**.
{% endstep %}

{% step %}
### Join

In CS 1.6 open the console (`~`) and type:

```
connect YOUR_SERVER_IP:27015
```
{% endstep %}
{% endstepper %}

## Ports

| Port | Protocol | Use |
|---|---|---|
| `27015` | UDP | Game connection and RCON |

Your assigned ports are always visible in the panel and may differ from these defaults.

## Plugins

Most servers use Metamod and AMX Mod X. Upload them to `cstrike/addons`, then add plugins to `addons/amxmodx/plugins` and list them in `plugins.ini`.

{% hint style="warning" %}
Use a strong `rcon_password`. Anyone who knows it can control your server.
{% endhint %}
