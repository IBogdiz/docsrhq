# MariaDB and HeidiSQL

This guide helps you install MariaDB on a Windows server and connect to it with HeidiSQL.

{% stepper %}
{% step %}
### Download and install MariaDB

Go to the official website [mariadb.org/download](https://mariadb.org/download) and download the latest version of the software.
{% endstep %}

{% step %}
### Download and install HeidiSQL

Go to the official website [heidisql.com/download.php](https://www.heidisql.com/download.php) and install HeidiSQL.
{% endstep %}

{% step %}
### Connect to MariaDB with HeidiSQL

Start HeidiSQL and create a new session to begin the connection process.
{% endstep %}
{% endstepper %}
