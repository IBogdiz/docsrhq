# Server Counter-Strike 1.6

Serverul tău Counter-Strike 1.6 rulează pe panoul nostru de jocuri (Pterodactyl). Este mic și pornește în câteva secunde.

{% stepper %}
{% step %}
### Pornește serverul

Deschide serverul în panoul de jocuri și apasă **Start**.
{% endstep %}

{% step %}
### Configurează-l

În tabul **Files** editează `cstrike/server.cfg`: `hostname`, `sv_password`, `rcon_password` și `sv_lan 0`.
{% endstep %}

{% step %}
### Setează hărțile

Editează `cstrike/mapcycle.txt` ca să alegi rotația hărților și setează harta de start în **Startup**.
{% endstep %}

{% step %}
### Conectează-te

În CS 1.6 deschide consola (`~`) și scrie:

```
connect IP_SERVER:27015
```
{% endstep %}
{% endstepper %}

## Porturi

| Port | Protocol | Folosire |
|---|---|---|
| `27015` | UDP | Conexiunea la joc și RCON |

Porturile alocate ție sunt mereu vizibile în panou și pot diferi de cele implicite.

## Pluginuri

Majoritatea serverelor folosesc Metamod și AMX Mod X. Încarcă-le în `cstrike/addons`, apoi pune pluginurile în `addons/amxmodx/plugins` și listează-le în `plugins.ini`.

{% hint style="warning" %}
Folosește un `rcon_password` puternic. Oricine îl știe poate controla serverul tău.
{% endhint %}
