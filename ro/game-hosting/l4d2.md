# Server Left 4 Dead 2

Serverul tău Left 4 Dead 2 rulează pe panoul nostru de jocuri (Pterodactyl). La prima pornire se descarcă fișierele jocului prin SteamCMD.

{% stepper %}
{% step %}
### Pornește serverul

Deschide serverul în panoul de jocuri și apasă **Start**. Așteaptă până când consola arată că serverul rulează.
{% endstep %}

{% step %}
### Permite conexiunile directe

În tabul **Files** editează `left4dead2/cfg/server.cfg` și adaugă `sv_allow_lobby_connect_only 0`. Fără asta jucătorii pot intra doar printr-un lobby.
{% endstep %}

{% step %}
### Setează elementele de bază

În același fișier setează `hostname`, `sv_password` și `rcon_password`. Alege modul de joc cu `mp_gamemode` (de exemplu `coop` sau `versus`).
{% endstep %}

{% step %}
### Conectează-te

În Left 4 Dead 2 activează consola de developer, apoi scrie:

```
connect IP_SERVER:27015
```
{% endstep %}
{% endstepper %}

## Porturi

| Port | Protocol | Folosire |
|---|---|---|
| `27015` | UDP și TCP | Conexiunea la joc și RCON |

Porturile alocate ție sunt mereu vizibile în panou și pot diferi de cele implicite.

## Schimbarea hărții

Scrie în **Console**:

```
changelevel c1m1_hotel
```

## Pluginuri

Instalează Metamod și SourceMod în `left4dead2/addons`, apoi adaugă pluginurile în `addons/sourcemod/plugins`.
