# Panoul de jocuri

Toate serverele de jocuri RHQ rulează pe panoul nostru (Pterodactyl). Panoul arată la fel pentru toate jocurile, deci odată ce îl știi poți administra orice server.

## Panoul pe scurt

| Tab | La ce folosește |
|---|---|
| **Console** | Pornește, oprește și repornește serverul, citește logul live și scrie comenzi |
| **Files** | Navighează, editează și încarcă fișiere precum configurări, pluginuri și moduri |
| **Startup** | Numele serverului, versiunea jocului, chei de licență și alte setări de pornire |
| **Network** | Adresa IP și porturile alocate serverului tău |

{% hint style="info" %}
**Oprește** mereu serverul înainte să editezi fișiere importante. Unele jocuri suprascriu configurarea când se închid.
{% endhint %}
