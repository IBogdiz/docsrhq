# MariaDB și HeidiSQL

Acest ghid te ajută să instalezi MariaDB pe un server Windows și să te conectezi la el cu HeidiSQL.

{% stepper %}
{% step %}
### Descarcă și instalează MariaDB

Intră pe site-ul oficial [mariadb.org/download](https://mariadb.org/download) și descarcă cea mai recentă versiune a programului.
{% endstep %}

{% step %}
### Descarcă și instalează HeidiSQL

Intră pe site-ul oficial [heidisql.com/download.php](https://www.heidisql.com/download.php) și instalează HeidiSQL.
{% endstep %}

{% step %}
### Conectează-te la MariaDB cu HeidiSQL

Pornește HeidiSQL și creează o sesiune nouă ca să începi conectarea.
{% endstep %}
{% endstepper %}
